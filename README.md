#  EdTech Academy Launch // Modern Online Learning Platform UI

A high-performance, conversion-focused landing page and UI portfolio concept designed for online academies, educational technology platforms, and digital skill bootcamps. Engineered with clean course structures, interactive learning cards, and a lightweight responsive architecture.

---

##  Key Architectural Features
- **Modern EdTech Aesthetic:** High-contrast dark aesthetic with vibrant amber/violet accents, structured curriculum cards, and dynamic CTA sections.
- **Pure Vanilla JavaScript & Tailwind:** Zero heavy frameworks to guarantee lightning-fast page loading and rapid DOM manipulation.
- **Fully Responsive Layout:** Seamlessly optimized across mobile, tablet, and high-resolution desktop viewports.

---

## Technology Stack
- **Markup:** HTML5 (Semantic & Accessible)
- **Styling:** Tailwind CSS (Utility-first framework)
- **Scripting:** Pure Vanilla JavaScript (ES6+)
